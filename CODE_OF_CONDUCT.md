# Code of conduct

## In short

Be decent. This is a small project about keeping people's private conversations private;
treat the people in it the same way.

## Expected

- Assume good faith, especially across languages — this project has English and Persian
  speakers and neither is anyone's obligation to write perfectly.
- Keep criticism about the code, the behaviour, or the decision.
- Respect that a maintainer's time is donated, and that "no" is a complete answer to a
  feature request.

## Not acceptable

- Harassment, insults, or personal attacks
- Discriminatory language of any kind
- Publishing someone's private information
- Posting screenshots or logs containing other people's messages. The project's own tools
  redact message content for exactly this reason; do not work around them.

## Enforcement

Report a problem by opening a private security advisory or contacting the maintainer
directly. Reports are handled confidentially. Maintainers may edit, remove or reject
contributions that violate this document, and may block repeat offenders.
