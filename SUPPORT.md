**Something stopped blurring after a Bale update?**
You do not have to wait for a release: the options page lets you add your own CSS
selector to any category. See [Selector maintenance](https://github.com/amiranmanesh/bale-privacy-extension/wiki/Selector-Maintenance).

**Still stuck?** [Open an issue](https://github.com/amiranmanesh/bale-privacy-extension/issues/new/choose). The forms ask for the
diagnostics that make a fix quick — and both diagnostic tools redact message content
before printing, so their output is safe to paste.

**Found a vulnerability?** Please report it privately — see [SECURITY.md](SECURITY.md).
